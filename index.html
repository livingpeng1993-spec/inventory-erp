🔥 连接 Firebase 实现多设备同步

只需 3 步，所有团队成员打开同一个 HTML 文件就能实时共享数据。完全免费（Spark 套餐足够日常使用）。

💡 配置信息保存在本地浏览器，每台设备首次打开需要填写一次。之后直接使用，数据实时同步。
打开 Firebase Console， 点击「Add project」→ 输入项目名（如 erp-inventory）→ 创建完成后点击「Web」图标 (</>) 注册应用。
在左侧菜单 「Build」→「Firestore Database」→「Create database」→ 选 Start in test mode（方便测试，30天后需调规则）→ 选择最近的区域。
回到「Project settings」→「Your apps」→ 复制 firebaseConfig 里的各字段，粘贴到下方。
请填写 API Key、Auth Domain、Project ID 和 App ID
